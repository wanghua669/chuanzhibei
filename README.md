## 🚀 五大核心模块与业务闭环

### 1. 🧬 赛博电子分身系统 (CyberAvatar)
- **概念**：你的消费数据就是你的数字 DNA。系统根据你的账单数据动态渲染并进化你的“数字替身”；
- **自适应机制**：
  - 恩格尔系数高 $\rightarrow$ 分身变身【高碳水暴食机甲】；
  - 深夜剁手频繁 $\rightarrow$ 分身戴上【午夜全息黑眼圈面罩】，机体发出过热警告；
  - 极客消费占比高 $\rightarrow$ 装备【外骨骼装甲与 RGB 算力芯片】；
  - 结余率高、守财稳健 $\rightarrow$ 激活【高分子合金金钟罩】。

### 2. 🌌 平行宇宙时空穿梭镜 (Parallel Universe)
- **概念**：人们总觉得“几十块钱无所谓”，却不知道一年下来失去了什么；
- **双时空对照**：
  - **现实宇宙 A**：记录当前的实际流水与频繁冲动；
  - **平行宇宙 B**：把非必要冲动消费自动换算为理财或心愿基金；
- **时空穿梭镜**：在打算花大钱前，输入“想买 399 元游戏卡带”，AI 瞬间推演未来 30 天两个平行宇宙的生活质感分流走向！

### 3. ⚖️ 赛博消费公诉法庭 (CyberCourt)
- **概念**：把消费冲动送上法庭，破解大数据消费主义洗脑套路；
- **多智能体质询对抗**：
  - **公诉人 AI**：代表你的未来钱包，无情辩驳戳穿虚荣买单与冲动理由；
  - **用户（被告）**：提交购买理由抗辩；
  - **AI 陪审团与法官**：最终判决【当庭驳回】或【附带惩罚缓刑执行】（如“罚做深蹲30个以解锁购买资格”）。

### 4. ⚔️ 现实地下城生存战报 (SpendQuest RPG)
- **概念**：把反人性的存钱自律变成打怪升级的 RPG 生存冒险；
- **战报机制**：
  - 月收入是你的总生命值 HP，每笔消费是一场怪兽遭遇战（疯狂星期四 = 遭遇暴食火龙）；
  - **TCG 现实战力卡牌**：由大模型根据你的账单行为，自动生成可收藏打卡的专属实体卡牌（如“早八生椰拿铁续命卡”、“二手闲鱼回血卡”）。

### 5. 💳 微信无感智能免打字对账 (Smart Ledger)
- **彻底解决“手动记账太烦”的痛点**：
  - **方案 A（官方账单一键同步）**：支持拖入微信【下载账单-用于个人对账】导出的官方 CSV，0.1秒自动解析几百笔流水，0 手动录入！
  - **方案 B（剪贴板免打字入账）**：复制微信支付通知文本或截图，在软件内直接按 `Ctrl + V`，智能正则即刻提取商户与金额；
  - **方案 C（微信实时流水模拟器）**：提供实时 Webhook 事件流推演模式，展示高并发账单到达时图表与分身的毫秒级动态联动。

## 🛠️ 技术架构与选型

| 模块 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **基础工程** | Vite 8 + React 19 + TypeScript | 毫秒级热更，全链路强类型安全 |
| **视觉与窗口** | Tailwind CSS 3 + Cyberpunk Desktop Chrome | 桌面应用外壳、发光霓虹、窗口控制 |

| **大模型决策中枢** | DeepSeek-V3 / Flash API (`deepseek-chat`) | 多 Agent 辩护、分身演化、战报卡牌生成 |
| **双轨容灾机制** | Zero-Crash Offline Rule Engine | 网络断连/超时 100% 毫秒保底，演示零白屏 |
| **音效系统** | Web Audio API 纯原生合成 | 赛博微点击、木鱼重低音、法庭敲槌音效 |
| **跨端与移动端打包** | HBuilder X 深度兼容 (`base: './'`) | 一键打包 Android APK、iOS 或桌面端应用 |

## 💻 快速运行与打包

```bash
# 1. 克隆仓库
git clone https://github.com/wanghua669/chuanzhibei.git
cd chuanzhibei

# 2. 安装依赖并启动
pnpm install
pnpm dev

# 浏览器访问：http://localhost:3000
```

### HBuilder X 一键打包
项目构建配置已针对相对基路径优化：
```bash
pnpm build
```
编译生成的 `dist/` 目录可直接在 **HBuilder X** 中打开，选择【发行】$\to$【原生 App 云打包】即可生成移动端安装包！
